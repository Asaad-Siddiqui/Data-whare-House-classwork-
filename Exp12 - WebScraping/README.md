These notebooks practise requesting permitted public practice pages, parsing HTML with BeautifulSoup, cleaning data, saving CSV files, and making a chart.

## How to run

1. Open a notebook in VS Code with the Python and Jupyter extensions, or use Google Colab.
2. Make sure the environment has internet access.
3. Select a Python 3 kernel and run the cells from top to bottom.

Install dependencies from the repository root with `python -m pip install -r requirements.txt`. The notebooks may create CSV files in this folder when their export cells run.

## Responsible use

Use these notebooks only with permitted practice sites, respect `robots.txt`, follow the site's terms, use a reasonable request rate, and do not scrape private or restricted content.

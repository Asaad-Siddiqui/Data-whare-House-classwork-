# Experiment 7: K-means Clustering

These notebooks introduce K-means with the Iris dataset, model selection using the Elbow and Silhouette methods, a NumPy implementation from scratch, and customer clustering.

## Files

- [chit-19] K-means on Iris with K = 3: [open notebook](%5Bchit-19%5DKMeans-K3-Iris.ipynb)
- [chit-20] Elbow curve and Silhouette score: [open notebook](%5Bchit-20%5DElbow-Silhouette.ipynb)
- [chit-21] K-means from scratch: [open notebook](%5Bchit-21%5DKMeans-From-Scratch.ipynb)
- [chit-22] Mall Customers clustering: [open notebook](%5Bchit-22%5DMall-Customers-Clustering.ipynb)

## How to run

1. Open a notebook in VS Code with the Python and Jupyter extensions, or use Google Colab.
2. Select a Python 3 kernel.
3. Run cells from top to bottom.

The Iris and scratch examples run with built-in or embedded data. Chit 22 uses an embedded sample when `Mall_Customers.csv` is not present; place that CSV beside the notebook if you want to use the full dataset.

Install dependencies from the repository root with `python -m pip install -r requirements.txt`.

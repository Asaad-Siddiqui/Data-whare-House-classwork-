# Experiment 5: Data Transformation and Skewness

These notebooks demonstrate skewness transformations, IQR and Z-score outlier detection, winsorisation, encoding, and correlation analysis.

## Files

- [chit-15] Skewness transformations: [open notebook](%5Bchit-15%5DSkewness-Transformations.ipynb)
- [chit-16] IQR outlier detection: [open notebook](%5Bchit-16%5DIQR-Outlier-Detection.ipynb)
- [chit-17] Z-score outliers and winsorisation: [open notebook](%5Bchit-17%5DZScore-Winsorisation.ipynb)
- [chit-18] Encoding and correlation heatmap: [open notebook](%5Bchit-18%5DEncoding-Correlation-Heatmap.ipynb)

## How to run

1. Open the notebook in VS Code with the Python and Jupyter extensions, or use Google Colab.
2. Select the project Python environment.
3. Run every cell from top to bottom.

The notebooks use embedded sample data. Install dependencies from the repository root with `python -m pip install -r requirements.txt`.

## What to observe

Check how transformations affect skewness, which values are detected as outliers, how capping changes summary statistics, and how encoded variables appear in the correlation matrix.

These notebooks cover descriptive analysis, missing-value handling, normalisation, standardisation, and discretisation.

## How to run

1. Open the notebook in VS Code with the Python and Jupyter extensions, or upload it to Google Colab.
2. Select a Python 3 kernel.
3. Run the cells from top to bottom.

The sample data is included in each notebook, so no CSV file is required. Install the common dependencies from the repository root with `python -m pip install -r requirements.txt`.

## What to observe

Compare the summary tables and transformed values, then review how each missing-value or scaling method changes the data.
